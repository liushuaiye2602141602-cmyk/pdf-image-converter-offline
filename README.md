# PDF Image Converter Offline | 本地 PDF 图片转换工具

PDF Image Converter Offline is a local Windows tool for PDF and image conversion. It supports image to PDF, PDF to image, image format conversion, PDF merge, PDF split, page extraction and page deletion.

PDF Image Converter Offline 是一个本地运行的 PDF / 图片转换工具，适合办公室日常使用。支持图片转 PDF、PDF 转图片、图片格式转换、PDF 合并、PDF 拆分、页面提取和页面删除。

## Features | 功能

* Image to PDF | 图片转 PDF
* PDF to JPG / PNG / WebP | PDF 转 JPG / PNG / WebP
* Image format conversion | 图片格式转换
* PDF merge | PDF 合并
* PDF split | PDF 拆分
* Extract PDF pages | 提取 PDF 页面
* Delete PDF pages | 删除 PDF 页面
* Offline local processing | 本地离线处理
* Windows desktop version | Windows 桌面版
* Windows 7 web version | Windows 7 本地网页端版本

## Projects | 项目版本

### 1. pdf-image-converter-desktop-win10-win11

Desktop PDF image converter for Windows 10 and Windows 11.

Win10 / Win11 桌面版 PDF 图片转换工具。

Tech stack: Python, PySide6, PyMuPDF, Pillow, pypdf, img2pdf, PyInstaller

### 2. pdf-image-converter-desktop-win7-test

Experimental Windows 7 desktop version.

Win7 桌面兼容测试版。

Tech stack: Python 3.8.10, PySide2, PyInstaller 5.13.2

Note: This version was used for Windows 7 desktop compatibility testing. It may have Qt or DLL compatibility issues on some Windows 7 systems.

注意：该版本用于 Win7 桌面兼容测试，部分 Win7 系统可能存在 Qt 或 DLL 兼容问题。

### 3. pdf-image-converter-web-win7

Local web version for Windows 7.

Win7 本地网页端可用版。

Tech stack: Python 3.8.10, Flask, Waitress, PyMuPDF, Pillow, pypdf, PyInstaller 5.13.2

Run locally: http://127.0.0.1:8765

All files are processed locally. No files are uploaded to the internet.

所有文件只在本机处理，不上传外网。
